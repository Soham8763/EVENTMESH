# Contributing to EventMesh

We love your input! We want to make contributing to EventMesh as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Becoming a maintainer

## Development Process

1. Fork the repo and create your branch from `main`.
2. Ensure you have the local infrastructure running (`docker compose up`).
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure the test suite passes.
6. Issue that pull request!

## Code Style

- Use `gofmt` for formatting.
- Write structured logs using `zap`.
- Every new feature should include Prometheus metrics.
