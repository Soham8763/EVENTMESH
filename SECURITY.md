# Security Policy

## Reporting a Vulnerability

We take the security of EventMesh seriously. If you believe you have found a security vulnerability in this project, please report it to us as soon as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to <soham@eventmesh.io> (fictional for demo).

### Scope

This security policy applies to all services within the EventMesh repository.

### Response

The maintainers will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for resolution.
