# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-22

### Added

- Initial release of EventMesh.
- Core 5-service architecture (Auth, Ingestor, Rule Engine, Orchestrator, Worker).
- Distributed tracing with OpenTelemetry.
- Prometheus metrics for all services.
- Redis-based idempotency and lease management.
- Chaos testing report and automation.
- Comprehensive production-grade documentation.
- `run_demo.sh` for automated system walkthrough.
